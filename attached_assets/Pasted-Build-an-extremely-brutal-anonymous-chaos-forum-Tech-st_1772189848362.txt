Project name: ritual48

==================================================
CORE CONCEPT
==================================================

This is not a friendly forum.
Posts live for 48 hours only.
Users cannot edit posts.
Votes have real consequences.
Threads can die.
Users can become "Public Enemy".

==================================================
AUTH SYSTEM
==================================================

- Supabase email + password auth
- profiles table linked to auth.users
- role: user / admin
- is_banned boolean
- shadow_banned boolean

If shadow_banned = true:
User sees their posts normally,
But other users cannot see their posts or comments.

==================================================
DATABASE SCHEMA
==================================================

TABLE profiles
- id uuid primary key references auth.users(id)
- username text unique
- role text default 'user'
- is_banned boolean default false
- shadow_banned boolean default false
- reputation integer default 0
- created_at timestamp default now()

TABLE posts
- id uuid primary key default gen_random_uuid()
- title text not null
- content text not null
- user_id uuid references profiles(id)
- score integer default 0
- heat integer default 0
- expires_at timestamp not null
- is_deleted boolean default false
- is_locked boolean default false
- created_at timestamp default now()

TABLE comments
- id uuid primary key default gen_random_uuid()
- post_id uuid references posts(id)
- user_id uuid references profiles(id)
- parent_id uuid references comments(id)
- content text not null
- score integer default 0
- is_deleted boolean default false
- created_at timestamp default now()

TABLE votes
- id uuid primary key default gen_random_uuid()
- user_id uuid references profiles(id)
- post_id uuid
- comment_id uuid
- value integer check (value in (-1,1))
- created_at timestamp default now()

Add unique constraints for one vote per user per post/comment.

==================================================
BRUTAL RULES
==================================================

1) 48 Hour Death
expires_at = now + 48h
Expired posts:
- hidden from homepage
- shown as "THIS THREAD IS DEAD" if accessed directly

2) Collapse System
score < -50 → collapsed
score < -200 → hidden from homepage
score < -500 → locked automatically

3) Chaos Amplifier
If score is highly negative but comments > 50:
Boost heat score.
Order homepage by:
heat DESC, score ASC, created_at DESC

This pushes controversial posts higher.

4) Public Enemy
If a user total negative votes exceed -300:
Add badge: PUBLIC ENEMY
Display on all their posts.

5) Reputation System
Upvotes increase reputation.
Downvotes decrease.
If reputation < -200:
Automatically shadowban.
